# Native tiger statue inputs

These two unchanged RGBA pictures are shared AssetCatalog/native-compositor exports of patterns41781 and93225 (SOBJ3242-3244 and3245-3247). Each146x172 canvas has offset(-1,-123), source foot171 and axis73. Export metadata is in E:/repo/nexus/source-6/build/cloud1-guardian-native-model-inputs.

The authoring recipe makes fixed relief volumes: body depth0.35 cells, plinth depth1.25 cells from source row130. Both mirrored forms use the same recipe. The front retains native art; the back reuses its carving. Unseen geometry is approximate. Model-generation clears painted-shadow alpha at or below127; surviving source colour and alpha bytes stay unchanged. Textures are point-sampled sRGB without resizing or mipmaps.

The existing platform module build creates tiger-statues.bundle beside the hints. Generated assets are under the ignored Art/Bundle/Tigers folder of the Unity project being built. Nothing changes the original pack, Normal2D drawing, map cells, collision or packets.
