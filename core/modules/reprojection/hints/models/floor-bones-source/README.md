# Native floor-bone model inputs

The `tile-*.png` pictures are unchanged 48 by 48 exports of Kru 7.5.2 ground images, read through the editor's shared `AssetCatalog.GroundImage`. The matching clean floor is979; the old1006 input is retained but unused. Export receipts remain in `G:/Nexus/work/s6-reprojection-cloud-1/owner-feedback/bone-native-art/`.

The five `mask-*.png` files mark bone pixels in source-picture coordinates, including their dark outlines. Coverage is the exact native difference from979 within two pixels of the original bone silhouette, excluding unrelated floor variation. Their grey values are used only as coverage, never as model height. Tile1011's head and jaw are separate parts.

`FloorBoneModels.Make` builds the models into `floor-bones.bundle` beside the reprojection hints, through the normal module build for its target platform. It now uses the shared `HelperShapes` assets: native faces, lying bones and floor patches are 2-triangle quads; each skull back is the same 32-triangle dome fitted inside its cranium. Whole prefabs have 4 triangles for lying bones, 36 for1009 and38 for1011 including its jaw. Native colour/alpha textures retain the fine outlines; there is no pixel-built mesh. `NativeSurfaceMaps` derives a small normal-detail map from the cutout's alpha and native brightness and places it in the existing prefab material's `_BumpMap` slot. The reprojection model path retains that map and its `_BumpScale`; unmapped models preserve their original shading. The map changes the surface normal, not geometry or the native picture. In the inspected room lighting its visible effect on the bones is negligible because the directional shade is already clamped near full brightness; their painted detail remains in the native colour texture. The skull face preserves the native default-camera projection and its back uses a middle-tone native texel. The floor patch replaces only covered pixels with979; the rest stays unchanged. No parallax or height displacement is claimed.

Textures remain48 by48, point sampled, uncompressed, without mipmaps, in sRGB colour space. No original pack, map, 2D drawing or gameplay data changes. Generated assets live under the ignored `Art/Bundle/FloorBones` folder in the Unity project being built, whether staged or the normal client project.
