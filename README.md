# MR-TK Public-Test

**Download the game from this repository's release: [build-next72-pt.zip](../../releases/download/next72-pt/build-next72-pt.zip)**
(also under **Releases**, on the right of this page). Unpack it anywhere and start `MR-TK.exe`; it connects to the
Dev server.

The zip holds everything, the game's art too. The green **Code > Download ZIP** button and the release's "Source
code" archives do not hold the art (GitHub keeps the art packs apart), so a client unpacked from them says it has no
art packs.

`README.txt` explains the folders, updating and the command line.
